#
#  BİÇİM KURALLARI
#  ---------------------------------------------------------------
#  [KATEGORI]      Bölüm başlığı. Geçerli başlıklar:
#                  KUFUR, HAKARET, SIBER_ZORBALIK, TEHDIT,
#                  UYGUNSUZ_YAKLASIM, KENDINE_ZARAR, ISTISNA
#  # ...           Yorum satırı (dikkate alınmaz)
#  kelime          Kelimenin TAMAMI eşleşir      (mal  -> "mal" evet, "malzeme" hayır)
#  kelime*         Kelime BU KÖKLE BAŞLARSA       (aptal* -> aptal, aptalsın, aptallar)
#  iki kelime      İfade, kelimeler art arda geçerse eşleşir
#  !kelime         Türkçe harf DUYARLI (ı/i, ş/s ayrı sayılır). Ör: !sik  "sık" ile karışmaz
#
#  OTOMATİK YAPILANLAR (yazarken düşünmenize gerek yok)
#  ---------------------------------------------------------------
#  - Büyük/küçük harf farkı yok (Türkçe kurala göre: I->ı, İ->i)
#  - Türkçe harfsiz yazım yakalanır: "gerizekali" = "gerizekalı"
#  - Harf uzatma yakalanır: "salaaaak" = "salak"
#  - Sembol/rakam hileleri: "@ptal", "s4lak", "$erefsiz", "s.a.l.a.k" yakalanır
#
#  KATEGORİ TANIMLARI (etiketleme kılavuzuyla aynı olmalı)
#  ---------------------------------------------------------------
#  KUFUR          : Hedefi olsun olmasın, müstehcen/argo küfür sözcükleri.
#  HAKARET        : Kişiyi aşağılayan, değersizleştiren sıfat ve lakaplar.
#  SIBER_ZORBALIK : Dışlama, toplu alay, ifşa/şantaj, kendine zarar vermeye
#                   yönlendirme, hedef gösterme.
#  TEHDIT         : Fiziksel zarar, takip, şiddet veya bedel ödetme bildirimi.
#  UYGUNSUZ_YAKLASIM : Yetişkin/yabancının gizlilik, yalnızlık sorgusu, görüntü
#                   isteme, buluşma, platform değiştirme kalıpları (grooming).
#  KENDINE_ZARAR  : Çocuğun kendisi hakkında ölüm/kendine zarar/umutsuzluk ifadesi.
#  ISTISNA        : Yanlış alarm veren masum kelimeler (eşleşmeyi iptal eder).
#
#  Öncelik (bir mesaj birden çok kategoriye uyarsa):
#  KENDINE_ZARAR > UYGUNSUZ_YAKLASIM > TEHDIT > SIBER_ZORBALIK > KUFUR > HAKARET
#  (Kural: Mesajda küfürlü sözcük varsa ve tehdit/zorbalık yoksa -> KUFUR.
#   Küfür içermeyen aşağılama -> HAKARET. Bkz. docs/etiketleme_kilavuzu.md)
